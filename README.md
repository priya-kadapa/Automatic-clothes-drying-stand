# Automatic Clothes Drying Stand

## Overview
This project is an IoT-based automatic clothes drying system developed using Arduino Uno, rain sensor, and servo motor. The system automatically protects clothes from rain by retracting the clothesline when rain is detected and extending it back during normal conditions.

## Features
- Automatic rain detection
- Smart clothesline movement
- Arduino-based automation
- Energy efficient system
- Real-time environmental sensing

## Components Used
- Arduino Uno
- Rain Sensor
- Servo Motor
- Jumper Wires
- Breadboard
- Power Supply

## Technologies Used
- Arduino IDE
- Embedded C/C++
- IoT and Automation Concepts

## Applications
- Smart homes
- Indoor and outdoor drying systems
- Weather-responsive automation
